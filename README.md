## 🚀 Overview
**Snake Master** is a classic snake game where the player navigates a snake to collect food while avoiding walls and its own tail.  
Fully implemented in **JavaScript**, entirely written by **Jumplander AI**.

## 💡 Features
- Smooth movement and responsive controls  
- Food collection and score tracking  
- Dynamic speed increase as the game progresses  
- Reset on collision with walls or tail
