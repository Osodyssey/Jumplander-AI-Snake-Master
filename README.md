# 🐍 JumpLander AI: Snake Master

**Snake Master** is a simple browser-based Snake game built as a small educational JavaScript project under the **JumpLander AI Academy** direction.

The goal of this project is to demonstrate how classic programming exercises can be used for learning, experimentation, and AI-assisted development workflows.

---

## 🚀 Overview

Snake Master is a classic Snake game where the player controls a snake, collects food, increases the score, and avoids collisions with the wall or the snake’s own body.

This project is intentionally simple and beginner-friendly.

It can be used to learn:

- Basic JavaScript logic
- DOM interaction
- Keyboard controls
- Game loops
- Collision detection
- Score tracking
- Small project structure
- Browser-based development

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/JumplanderAI-SnakeMaster.git
```

Navigate to the project folder:

```bash
cd JumplanderAI-SnakeMaster
```

Open the project:

```bash
open index.html
```

On Windows, you can simply double-click `index.html`.

You can also use VS Code Live Server:

```text
Right-click index.html → Open with Live Server
```

## 🎮 How to Play

Use the keyboard arrow keys to control the snake:

| Key | Action |
| :--- | :--- |
| **Arrow Up** | Move up |
| **Arrow Down** | Move down |
| **Arrow Left** | Move left |
| **Arrow Right** | Move right |

Goal:

- Collect food
- Increase your score
- Avoid walls
- Avoid hitting your own tail

## 🧠 Learning Notes

This project can help beginners understand important programming concepts:

### Game Loop

The game repeatedly updates the snake position, checks collisions, renders the board, and handles user input.

### State Management

The game keeps track of:

- snake position
- food position
- current direction
- score
- collision state
- game speed

### Collision Detection

The game checks whether the snake hits:

- the wall
- its own body

### Event Handling

Keyboard events are used to change the snake’s direction.
